## اپیک ۱: زیرساخت کلاینت فلاتر دسکتاپ و ضبط صدا (Flutter Desktop & WASAPI)

### [x] تسک ۱.۱: راه‌اندازی پروژه Flutter Desktop برای ویندوز (تکمیل شده)
* **اولویت:** P0 (بسیار بالا)
* **نوع:** Feature / Setup
* **شرح:** ایجاد ساختار پروژه فلاتر در مسیر `apps/client_flutter/` با پیکربندی پشتیبانی ویندوز، فایل `pubspec.yaml` و لایه‌های Core, Theme, Features.
* **معیار پذیرش (Definition of Done):**
  - ساختار پوشه‌بندی تمیز (Theme, Features, Core, Native) پیاده‌سازی شده باشد.

### [x] تسک ۱.۲: پیاده‌سازی پلاگین بومی C++ برای ضبط صدای سیستم (WASAPI Loopback) (تکمیل شده)
* **اولویت:** P0
* **نوع:** Native Engineering
* **شرح:** توسعه پلاگین C++ در زیرشاخه `windows/runner/` (`wasapi_capture_plugin.h/cpp`) برای اتصال به `IAudioClient` با فلگ `AUDCLNT_STREAMFLAGS_LOOPBACK` و تبدیل صدای سیستم به Linear PCM 16kHz Mono 16-bit و اتصال از طریق Dart FFI (`lib/native/wasapi_bindings.dart`).
* **معیار پذیرش:**
  - صدای خروجی اسپیکر/هدفون در حال پخش ویندوز به صورت بافرهای صوتی ۱۶ بیتی دریافت شود.
  - داده‌های صوتی از طریق Dart FFI بدون Memory Leak به کلاینت فلاتر پاس داده شوند.

### [x] تسک ۱.۳: طراحی رابط کاربری تاریک مدرن و کنترل نشست (تکمیل شده)

### [x] تسک ۱.۴: ساخت پنل شناور زیرنویس (HUD Overlay) (تکمیل شده)

## اپیک ۳: پایپ‌لاین هوش مصنوعی و دوبله زنده (AI Speech & Dubbing)

### [x] تسک ۳.۱: اتصال سرویس تبدیل گفتار به متن (Streaming STT - Deepgram Nova-2) (تکمیل شده)
* **اولویت:** P0
* **نوع:** AI Integration
* **شرح:** پیاده‌سازی آداپتور `DeepgramSTTAdapter` با مدل Nova-2 برای استریم چانک‌های صوتی PCM 16kHz و دریافت متن همراه با زمان‌مهر واژه‌ها با تاخیر زیر ۳۰۰ میلی‌ثانیه.
* **معیار پذیرش:**
  - تاخیر تشخیص گفتار زیر ۵۰۰ میلی‌ثانیه باشد.
  - پشتیبانی از حالت Mock Fallback در صورت غیاب کلید API.

### [x] تسک ۳.۲: ترجمه استریمی به زبان فارسی با کنترل طول کلام (تکمیل شده)
* **اولویت:** P0
* **نوع:** AI Integration / Prompt Engineering
* **شرح:** پیاده‌سازی پرامپت کنترل طول و ریتم هجاها در `GeminiTranslationAdapter` متناسب با مدت زمان کلام اصلی گوینده.
* **معیار پذیرش:**
  - خروجی فارسی روان و بدون تاخیر اضافه استریم شود.

### [x] تسک ۳.۳: ماژول شبیه‌سازی صدا و تبدیل متن به گفتار (Voice Cloning TTS - ElevenLabs) (تکمیل شده)
* **اولویت:** P1
* **نوع:** AI Integration
* **شرح:** پیاده‌سازی آداپتور `ElevenLabsTTSAdapter` با مدل `eleven_multilingual_v2` و خروجی مستقیم `pcm_16000` همراه با قابلیت استخراج پروفایل صوتی از نمونه صدای گوینده و Fallback خودکار به صدای پیش‌فرض فارسی.
* **معیار پذیرش:**
  - تولید مستقیم فرمت صوتی استاندارد PCM 16kHz Mono هماهنگ با ورودی Simli.
  - پشتیبانی از حالت Mock Fallback در صورت غیاب کلید API.

### [x] تسک ۳.۴: پیاده‌سازی الگوریتم تنظیم سرعت تطبیقی (Time-Stretching) (تکمیل شده)
* **اولویت:** P1
* **نوع:** Audio DSP
* **شرح:** تنظیم سرعت استریم صوتی فارسی (بین ۰.۸۵x تا ۱.۲x) با الگوریتم SOLA و حفظ زیروبمی صدا (Pitch Preservation) برای تطابق با بازه زمانی گوینده اصلی.
* **معیار پذیرش:**
  - صدا دچار اکو، رباتیک‌شدن یا ناهماهنگی زمانی نگردد.

### [x] تسک ۳.۵: پیاده‌سازی آداپتور اختصاصی Gemini API (Gemini Live / Flash Adapter) (تکمیل شده)
* **اولویت:** P0
* **نوع:** AI Adapter / Integration
* **شرح:** پیاده‌سازی آداپتور اختصاصی برای اتصال به Google Gemini API (مدل‌های Gemini 2.0 Flash و Multimodal Live API) از طریق اینترفیس‌های مشترک ارائه‌دهندگان (`TranslationProvider` و پایپ‌لاین استریمینگ).
* **معیار پذیرش:**
  - پیاده‌سازی کلاس `GeminiTranslationAdapter` مشتق‌شده از `TranslationProvider`.
  - استریمینگ توکن‌ها با تاخیر زیر ۴۰۰ میلی‌ثانیه برای ترجمه انگلیسی به فارسی.
  - خواندن ایمن API Key از متغیرهای محیطی سرور (`GEMINI_API_KEY`).
  - اعمال پرامپت کنترل طول و ریتم کلام گوینده برای هماهنگی با دوبله.

## اپیک ۴: هماهنگ‌سازی لب بلادرنگ (Cloud Real-Time Lip-Sync Engine)

### [x] تسک ۴.۱: پیاده‌سازی آداپتور ابری Simli برای لیپ‌سینک بلادرنگ (SimliLipSyncAdapter) (تکمیل شده)
* **اولویت:** P1
* **نوع:** Cloud AI Integration
* **شرح:** پیاده‌سازی اتصال به API سرویس Simli بر بستر WebRTC با دریافت مستقیم چانک‌های صوتی PCM 16kHz و پخش استریم ویدیوی چهره با تاخیر زیر ۳۰۰ میلی‌ثانیه.
* **معیار پذیرش:**
  - پیاده‌سازی کلاس `SimliLipSyncAdapter` منطبق بر اینترفیس `LipSyncProvider`.
  - ایجاد اتصال WebRTC و ارسال استریمی بافرهای صوتی بدون وقفه.
  - رله یا اتصال مستقیم ترک ویدیوی خروجی (H.264/VP9) به پلیر کلاینت فلاتر.

### [x] تسک ۴.۲: پیاده‌سازی MockLipSyncAdapter برای تست‌های محلی و بدون هزینه (تکمیل شده)
* **اولویت:** P1
* **نوع:** Testing / Tooling
* **شرح:** پیاده‌سازی آداپتور ساختگی (Mock) برای شبیه‌سازی رویدادهای استریم ویدیو یا برگرداندن ترک ویدیوی تستی بدون مصرف توکن و هزینه سرویس ابری.
* **معیار پذیرش:**
  - با تنظیم `LIPSYNC_PROVIDER=mock` سرور بدون وابستگی به کلید خارجی یا اتصال اینترنت، چرخه هماهنگی لب را شبیه‌سازی کند.

### [x] تسک ۴.۳: مکانیزم سوییچ خودکار و قطع تصویر در تاخیر بالا (Latency Circuit Breaker) (تکمیل شده)
* **اولویت:** P1
* **نوع:** Reliability
* **شرح:** پایش دائمی تاخیر WebRTC سرویس خارجی؛ در صورتی که تاخیر رفت و برگشت یا صف از ۱۰۰۰ میلی‌ثانیه فراتر رفت، ارسال فریم‌های ویدیو متوقف شده و سیستم بدون قطعی صدا به حالت Audio-only Fallback سوییچ کند.
* **معیار پذیرش:**
  - ارسال پیام هشدار `system.warning` با کد `HIGH_LATENCY_LIPSYNC` به کلاینت.
  - ادامه روان و بدون قطعی پخش صدای فارسی ترجمه‌شده.
